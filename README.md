# 싹딜 인터넷 가입 랜딩페이지

공개 주소: https://rkdid500.github.io/sakd-internet-landing/

- `index.html`: 배포용 페이지 (Tailwind CSS 컴파일 완료, 외부 의존 없음)
- `src-tailwind.html`: Tailwind v4 원본 소스 (수정 후 Tailwind CLI로 다시 컴파일)
- `img/`: 힉스필드(Higgsfield)로 생성한 이미지
- `PretendardVariable.woff2`: Pretendard 폰트 (SIL OFL)

출시 전 교체할 것: 138만원 구성 금액(예시 수치), 사은품 전체 목록(예시), 카카오톡 링크, 상담 폼 전송 연결.
